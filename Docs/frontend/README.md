# Frontend integration guidance

Implementation guides for frontend developers working with the ProboxAI API.

- [Authentication APIs](authentication.md): browser sign-in/session/logout,
  Telegram registration and password recovery, bearer clients, validation,
  errors, and integration checks.
- [Tasks board](tasks.md): full project board, task actions, sharing, recovery, accessibility, and backend gaps.
- [Projects APIs](projects.md): list/detail, creation and outcome recovery,
  settings, members, initialization, files/trash, archival, empty-project deletion,
  permissions, browser transport availability, and integration checks.

These guides describe the current repository implementation. Deployment and
environment availability must be checked separately.
