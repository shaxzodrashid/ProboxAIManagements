Tool status: in_progress/completed/failed/declined. Missing or unrecognized status defaults to completed for item.completed, otherwise in_progress. Item IDs match [a-zA-Z0-9_-]{1,128} or are null; known secret values in IDs cause ID omission.

Public command string, per-tool cwd, stdout/stderr, exit code, arguments and results are unavailable. Internally stdout JSONL and stderr are archived separately; neither is a public terminal-output contract. file_change contains no paths, read/add/edit/delete classification, counts, patch or before/after text. No standalone file_read event contract exists; reads can happen inside commands/MCP calls but cannot be classified publicly. Tool/server names, child-agent IDs, search queries/URLs/citations are excluded.

No public session tool-approval event/endpoint, progress percentage or exposed reasoning summary exists. The approval database model and project-owner deletion approval are not tool-approval contracts. A generic Working indicator may follow authoritative RUNNING state. Reasoning effort and reasoning-token metrics are metadata, not reasoning text. Hidden reasoning and unsupported reasoning items are omitted; never fabricate a summary. Visible prose is agent_message only.

## Envelope, updates and replay

Each event: {id,sessionId,turnId,sequence,type,createdAt,source,legacyProjection,data}. id is an event UUID; turnId can be null. Sequence orders all events within one session across turns. createdAt is persistence time, not a tool execution-duration measurement. SERVER source is reserved for current-version session.state/session.interruption. Legacy rows are reprojected with legacyProjection=true and never promoted to authoritative state. No viewer-as-author field exists.

Deduplicate by (sessionId,sequence). Group items by (sessionId,turnId,item.id); null IDs use sequence fallback, never merge nulls. Item IDs alone are not cross-turn identity. Text updates have no delta-versus-cumulative flag, offset or revision. Do not blindly concatenate updated text. Conservatively replace a known item with the latest observed frame, provisional until item.completed. Exact delta rendering needs verified provider normalization. Whole-session completion requires SERVER session.state or fresh session snapshot.

Authenticated current OPEN accounts with matching workspace, assigned-manager scope and sessions.read can read:

- GET /api/v1/sessions/:id: coherent session and chronological turns. Session cwd/model/effort and turn prompts/request IDs/token metrics follow DTOs; these are not per-tool payloads.
- GET /api/v1/sessions/:id/events?after=0&limit=100: after exclusive, limit 1..100, optional untilSequence. Response session/events/after/nextCursor/highWaterSequence/hasMore/historyAvailability=RETAINED_WITH_EXPLICIT_OMISSIONS. Capture first highWaterSequence as untilSequence for bounded pagination. Later snapshots can have larger lastSequence than that fixed boundary.
- GET /api/v1/sessions/:id/events/stream?after=<last-processed-sequence>: persisted replay then polling; SSE id is numeric sequence, type is envelope type, data is entire envelope. Last-Event-ID is an alternative; both must agree. untilSequence is unsupported on SSE.

Save processed cursor, reconnect after it, deduplicate delivery repeats. Stream rechecks authorization each batch and closes at token expiry. Refresh authentication/read REST history as appropriate; do not retry revoked access endlessly. Bad cursors 400/409; missing sequence 409 SESSION_HISTORY_UNAVAILABLE, never empty successful history. Missing/deleted session 404. Transport errors need authenticated REST reconciliation. No retention/pruning duration is promised.

POST /api/v1/sessions/:id/interrupt requires sessions.manage, assigned manager and {turnId:UUIDv4} bound to observed turn. Response interrupted (signal accepted), turnId, stopConfirmation, requestedAt, nullable signalAcceptedAt. Old targets cannot stop replacements; stale target 409. Unknown acknowledgment 503: read back same target, do not pick another automatically.

Stop evidence NOT_OBSERVED/NOT_STARTED/STOP_UNCONFIRMED/LOCAL_EXIT_OBSERVED. Local child close does not prove descendant containment. OWNER_LOST settles persisted state INTERRUPTED while preserving uncertainty. New follow-ups under STOP_UNCONFIRMED remain blocked pending approved acknowledgment policy.

## Bounds and missing richer contracts

Assistant text caps at 16,384 JavaScript characters with truncated marker. Known environment secret values at least 8 characters under matching secret-variable names are replaced with [REDACTED]. Best-effort exact replacement is not exhaustive; assistant text can contain private data, paths or secrets. Keep safe text/Markdown rendering.

New public persistence excludes raw tools/errors/reasoning. Existing JSONL/stderr/final binary Git diff archives remain server-side under existing storage policy. workspace.diff, workspace.diff_failed, runner.invalid_json publicly become runner.omitted. No public session-archive/diff download route. Separately authorized project-file routes show current filesystem, not historical tool reads/edits. Telegram generic labels/counters and reauthorized assistant-link downloads do not establish structured tool result contracts.

Terminal panes, command previews, file-read excerpts, historical diffs, tool args/results, approvals and exposed summaries need approved additive contracts. Verify actual runner schemas, visibility/retention, field bounds/redaction and permissions before projections/DTOs with replay/auth tests. Do not expose archives as a shortcut or infer provider schemas from a UI design.

## Endpoint gaps for the Space/UI checklist

These are missing capabilities, not approved payload names or implemented endpoint paths. The existing events/history/SSE routes would need additive contracts where indicated. No new external integration is implied. Parent/UI worker owns checklist IDs and additions.

For each richer read/stream contract, require stable session/turn/item binding, current authorization, replay ordering, explicit bounds/omissions, storage/retention decisions and safe rendering. An event-detail endpoint is optional architecture, not a mandate: small approved fields could instead extend the existing persisted event projection. Public raw archive access is not the default remedy.
